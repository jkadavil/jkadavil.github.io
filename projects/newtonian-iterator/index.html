Newton’s Method Iterator

A transistor-level implementation of one Newton’s Method iteration in static CMOS, combining a combinational divider with a signed subtractor and clocked feedback register.

PROCESSTSMC 0.2 μm
SUPPLY3 V
TRANSISTORS210
VERIFICATIONSpectre transient

01 — Overview

The hardware takes f(xₙ) and f′(xₙ) as supplied operands; it does not contain a separate circuit that evaluates an arbitrary function or derivative. The project focuses on the arithmetic update and its stored feedback.

This circuit implements one hardware update of Newton’s Method: xₙ₊₁ = xₙ − f(xₙ) / f′(xₙ). It extends my previously designed 2-bit unsigned CMOS divider with a 3-bit signed subtractor, an edge-triggered register, and register feedback into the next update.

The divider produces f(xₙ)/f′(xₙ); the subtractor calculates the signed two’s-complement result; and the register captures and feeds back the next xₙ on each rising clock edge. Each cell was designed and verified hierarchically before top-level integration.

02 — Architecture

2-bit CMOS divider3-bit signed subtractor3-bit clocked registerFeedback to subtractor

The quotient is zero-extended to 3 bits before subtraction. The register drives both the system output and feedback for the next update. The divider receives f(xₙ) and f′(xₙ) as input operands.

03 — CMOS Divider

The iterator builds on a 2-bit combinational CMOS divider that accepts unsigned operands and produces quotient and remainder, including a zero-checker for division-by-zero handling. Karnaugh-map minimization and compound CMOS gates—including AOI and OAI structures—support a compact implementation, while shared inverted signals reduce redundant circuitry.

Q1 uses NOR2; Q0 uses AOI with an inverter; R1 uses NAND4 with an inverter; and R0 uses OAI. Total divider count: 50 transistors.

04 — Signed Subtractor

Zero-extension happens before complementing the quotient. That keeps the unsigned divider result positive when it enters the three-bit arithmetic, then produces its three-bit two’s-complement negative value for addition. With three signed bits, the representable range is −4 through +3; results outside that range wrap in the available width.

Subtraction uses the two’s-complement identity D = xₙ − Q = xₙ + (~Q) + 1. Three full-adder cells form a ripple-carry structure; quotient bits are inverted before their corresponding adder stages, while the least-significant carry-in is tied high. The 2-bit quotient is zero-extended to 3 bits before subtraction, avoiding the need for a separate subtraction cell.

05 — Full-Adder Cell

The subtractor is constructed from three identical 28-transistor mirror-adder cells in static CMOS. Each receives A, B, and Carry In and produces Sum and Carry Out. The regular topology supports hierarchical implementation in Cadence Virtuoso, and each cell was verified across all eight input combinations before integration.

06 — Clocked Register

The register separates the current state from the next combinational result. Between clock edges, the divider and subtractor calculate the next update. At the rising edge, the register captures it and the feedback path presents that stored value to the next calculation. Because reset is synchronous, its value is captured through the input mux at the clock edge.

Each register bit uses an independent edge-triggered D flip-flop with a synchronous reset mux, master latch, and slave latch built from transmission gates and inverters. The master is transparent while CLK = 0; the slave is transparent while CLK = 1. At the rising edge, the master closes and the slave opens, transferring the stored value to Q. Three identical cells form Y[2:0], which also feeds back as xₙ.

07 — Hierarchical Implementation

The iterator contains the divider (zero checker, shared inverters, and Q/R logic), the three-bit subtractor (three full adders), and the three-bit register (three DFFs). Each lower-level cell was independently simulated before integration. This hierarchy isolates arithmetic and storage faults early, making top-level debugging more direct.

09 — Verification

Major subcells were verified before system integration. The full-adder was tested across all eight A, B, and carry-in combinations, then the complete design was exercised with the supplied vectors in Spectre transient simulation and checked against expected MATLAB values. All supplied test vectors passed within the 650 ns simulation window.

10 — Design Decisions

Two’s-complement subtraction: xₙ + (~Q) + 1 reuses regular full-adder cells.

Hierarchical verification: arithmetic, storage, and divider cells were simulated independently before integration.

Transmission-gate storage: master-slave latches provide transistor-level feedback storage and synchronous reset.

Reusable cells: identical full-adder and D flip-flop cells create a structured, repeatable hierarchy.

11 — Results

The completed design implements and stores one Newton’s Method update using transistor-level static CMOS arithmetic and storage: 3-bit signed two’s-complement arithmetic, a 2-bit combinational divider, and a 3-bit edge-triggered register. Total transistor count is 210 at a 3 V supply in TSMC 0.2 μm. All supplied vectors passed Spectre transient verification within 650 ns.

12 — What I Learned

This project strengthened my ability to translate an algorithm into a static CMOS architecture, work with two’s-complement arithmetic and compound logic, build hierarchical datapaths with transmission-gate storage, and validate subcells in Cadence/Spectre before system integration. It also sharpened my reasoning about transistor count, delay, and implementation complexity.

13 — Division-by-Zero Handling

The divider maps a zero divisor to one before evaluating the quotient and remainder. Its corrected bits are B′₁ = B₁ and B′₀ = B₀ OR NOT B₁. An inverter and NAND2 implement the correction in six transistors. For B = 00, the circuit therefore returns Q = A and R = 0; it does not issue an exception.

This also makes B′ = 00 unreachable in the downstream logic. I used those unreachable combinations as don’t-cares during Karnaugh-map minimization. The correction gives deterministic hardware behavior, but division by zero still has no valid Newton-method interpretation.

14 — Worked Arithmetic Update

As an illustrative arithmetic example, take stored xₙ = 000 (0), divider numerator A = 11 (3), and divisor B = 10 (2). Integer division produces Q = 01 (1) and R = 01 (1). The quotient is zero-extended before subtraction.

Qextended = 001
NOT Qextended = 110
D = 000 + 110 + 001 = 111  (−1)
Next rising edge: Y captures 111

The remainder is not used by the update, so 3/2 becomes the integer quotient 1 rather than 1.5. This example explains the datapath; it is not presented as an additional measured test vector. The three-bit signed result ranges from −4 to +3 and wraps on overflow. These arithmetic limits distinguish the circuit from a general-precision Newton solver.

15 — Gate-Level Tradeoffs & Divider Measurements

Q1 implements A1 AND NOT B′1 using NOR(NOT A1, B′1), reusing an inverted signal and avoiding an extra output inverter. Q0 uses an AOI followed by an inverter; R0 uses compound logic with the desired output polarity. R1 uses NAND4 plus an inverter: it costs 10 transistors and accepts a deeper NMOS stack because Q0 was the observed limiting output in the tested sequence.

I compared transistor widths of 300, 600, and 900 nm in the divider. The wider devices reduced delay but increased power enough that I retained 300 nm widths. I also tested input ordering within series stacks, rather than assuming equivalent Boolean arrangements had identical electrical delay.

The divider report measures delay from 50% supply crossings: 420.030328 ns − 419.995 ns = 35.328 ps. Its final power calculation is 9.1056 pJ / 640 ns ≈ 14.23 µW. These measurements describe the standalone divider under the report’s stimulus and loading, not the complete iterator or a guaranteed maximum clock frequency.

A clock limit for the full design would need the register clock-to-Q delay, combinational feedback delay, and setup time. The 650 ns verification window establishes the duration of the functional simulation, not the critical-path delay.
